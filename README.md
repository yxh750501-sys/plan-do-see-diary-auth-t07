# 플랜두씨 다이어리 2 · T07

T06의 최종 제출 소스 [`88778c3f9b3d20880c5a2d428abfe01b481eebf5`](https://github.com/yxh750501-sys/plan-do-see-diary-t06/tree/88778c3f9b3d20880c5a2d428abfe01b481eebf5)를 조상으로 이어 만든 로그인 다이어리입니다. 공개 첫 화면은 로그인 화면이며 자료 조회·변경은 서버 세션과 소유자 검사 뒤에만 처리합니다.

## 실행과 검사

```sh
npm ci
npm run build
npm run check
node tests/integration.mjs
```

로컬 통합 검사는 임시 SQLite DB와 합성 계정을 사용합니다. 그 검사에서 만든 5일 데이터는 공개 사이트의 실제 5일 사용 기록이 아닙니다.

## T06 자료 가져오기

1. T06 공개 결과물에서 `전체 JSON 내보내기`로 파일을 받습니다.
2. T07에서 본인만 아는 아이디와 비밀번호로 가입합니다. 비밀번호를 채팅이나 제출 파일에 적지 않습니다.
3. 로그인한 다이어리의 `T06 자료 가져오기`에서 파일을 선택합니다. 기존 ID는 새 ID로 매핑하고, 자료는 로그인한 계정 소유로 저장됩니다.

가져오기는 계획이 없는 계정에서 한 번만 허용됩니다. 기존 T06 공개 사이트의 원본 자료는 이 작업만으로 삭제되지 않습니다.

## 인증과 자료 보호

- `bcryptjs 3.0.3`의 bcrypt(비용 12)로 계정별 소금값이 붙은 비밀번호 해시를 저장합니다.
- 무작위 256비트 세션 값은 `HttpOnly; Secure; SameSite=Lax` 쿠키에 두고, DB에는 그 값의 SHA-256 해시와 7일 만료 시각만 저장합니다.
- 로그아웃은 해당 서버 세션을 삭제합니다. 비밀번호 변경은 계정의 모든 세션을 삭제합니다.
- 모든 계획·할 일·실행 기록·일별 자료 읽기와 변경은 로그인한 소유자 ID로 제한합니다.
- 로그인하지 않은 `/diary`는 로그인 화면으로 이동하고, 자료 API는 HTTP 401을 반환합니다.

인증 구현과 요청·응답 검사 기록은 [`docs/T07-인증-구현-설명서.md`](docs/T07-인증-구현-설명서.md)에 있습니다. 실제 5일 사용 기록과 공개 배포 검사는 시작 전까지 완료로 표시하지 않습니다.
